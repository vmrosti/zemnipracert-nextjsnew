# RT® — Ground in Motion

A fresh, experimental Next.js concept for Zemní práce RT. This intentionally avoids the previous conventional construction-business layout. It uses a dark editorial art direction, acid-lime accents, animated topographic contours, pointer-reactive hero composition, full-screen menu, scroll reveals, and interactive capability modules.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before production

- Replace illustrative location coordinates and claims with verified company details.
- Connect the demo inquiry form to a real backend/email provider.
- Confirm the correct business contact details and services.
- Fonts currently load from Google Fonts; self-host them if desired.

The visual terrain artwork is generated with inline SVG/CSS, so no stock-photo download is required for the primary visual system.
